# WanderQuest

WanderQuest is a location-aware AR scavenger-hunt RPG for the RayNeo X3 Pro glasses that turns the wearer's actual neighborhood into a fantasy realm. It pulls real map data from OpenStreetMap and translates it into an in-world geography — parks become the Whispering Wilds, libraries become Lore Citadels, public bookcases become Fonts of Fellowship — so quests, monsters, and loot are anchored to real places the player has to walk to. Positioning runs on a step-based dead-reckoning engine layered under an optional phone-GPS bridge rather than any Google location service, so the game degrades gracefully from precise outdoor tracking down to an offline "Mistlands" mode with no map data at all. Progress and combat are handled through short, glanceable interactions, and story beats are delivered as single-sentence, audio-only narration with no on-screen captions, keeping the heads-up display nearly empty while walking.

## Controls (right temple pad primary, left pad secondary)

- Tap — interact / pick up / strike / select
- Double-tap — open the main menu, or exit the current screen
- Swipe forward/back — switch the held weapon or item
- Swipe up/down — radar zoom / navigate menu lists
- Triple-tap — reset the compass trim
- Left tap — use the held special item
- Head shake or nod (combat only) — strike; any head movement during a monster's lunge — duck
